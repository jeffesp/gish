# Gish Codebase Constraints (Agents Guide)

## General Availability
Gish is a specialized, local codebase/tooling and is not a generally available or externally published program. Therefore:

1.  **Web Search Prohibition:** All agents are strictly prohibited from performing general web searches (`WebSearch` or similar calls) concerning the internal architecture, function definitions, specific bug fixes, or private feature roadmaps of Gish.
2.  **Internal Focus:** Agent work must remain focused on the source code provided and the technical details within the local files.

This constraint applies to all agents to prevent wasted effort on external validation that cannot be provided by public APIs.
